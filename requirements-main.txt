# The library's main branch, for the examples in etc/unreleased.txt.
#
# Six of the examples here show capabilities that landed after 0.3.0 was cut —
# the five optional codecs, encrypted bodies, development certificates, the
# saga, the scheduler and the OpenTelemetry adapter. None of them are in the
# 0.3.0 wheel on the index, so an example using them cannot resolve the release
# and there is no version to pin instead.
#
# It resolves from the public repository rather than from a checkout beside
# this one, so CI installs what a reader would get and a clone of this
# repository alone is enough to run everything in it.
#
# This file is temporary by design. When 0.4.0 is released, every example moves
# to requirements.txt, etc/unreleased.txt empties, and this file goes.
acemq-amqp[rabbitmq,prometheus,yaml,toml,protobuf,avro,crypto,opentelemetry] @ git+https://github.com/AceMQ-Company/acemq-python-amqp@main

# The tracing example configures a tracer provider so there is something to
# print. The library depends on the OpenTelemetry *API* alone and exports
# nothing without an SDK, which is the point — installing an application's
# telemetry stack is the application's decision, so it is declared here rather
# than pulled in by an extra.
opentelemetry-sdk>=1.20
